ToB 合作案例查询 AI Agent

面向销售投标中历史案例分散、跨系统查询与权限协作繁琐的问题，参与 Agent 产品方案设计：将自然语言需求转为按需调用的工具链，在授权范围内汇总案例、业务数据与相关材料。

ReAct 动态编排19 个 CLI 工具L1–L4 分级访问控制模型＋代码双层安全护栏
01 / DISCOVERY

业务问法结构化与澄清

从 500 余条业务问法中提炼客户、项目、时间和金额等参数，设计缺参反问与歧义消解规则，让模糊需求转为可执行查询。

02 / ORCHESTRATION

ReAct 动态编排

围绕客户→项目→数据→补充查询设计动态路由；根据已知参数和工具返回跳过冗余步骤，按需调用 19 个 CLI 工具。

03 / L1–L4 SECURITY

L1–L4 分级访问控制

L1 基础信息授权可见；L2 业务数据按角色及组内／跨组关系控制、跨组区间脱敏；L3 合同与发票审批交付；L4 成本、毛利等禁止输出。

04 / GUARDRAILS

模型＋代码双层安全护栏

模型层通过 Prompt / Skill 声明安全边界；代码层由 CLI / 过滤器强制鉴权、脱敏和拦截，在数据返回模型前执行规则，避免仅靠提示词防越权。

05 / CONTEXT

多轮上下文与异步审批

保留已确认参数与授权结果摘要，承接连续追问；L3 审批等待期间先交付可见信息，审批通过后再按授权范围补充材料。

06 / ITERATION

Bad Case 归因与评测迭代

从参数解析、工具路由、权限红线和结果呈现定位问题，针对性迭代规则与输出模板；以查询耗时为北极星指标，配套正确性与安全验收。

RESEARCH & PRACTICE

研究与工程实践

船海工程背景 · 工业 AI 应用
01 / INTERNATIONAL STANDARD

船舶安全瞭望
从工程方案到国际标准

将船员作业经验与设备约束，转化为动态安全边界、产品功能及量化验收判据。

相关提案获 ISO/TC 8 批准立项
＋
核心方法综合本船操纵性能、相对运动与会遇关系，计算不同工况下的最小安全瞭望距离与区域；据此设计多源信息加权、风险排序、追踪预测及盲区补偿方案。
交付重点把安全等效方法落实为区域确定流程、测试场景与量化判据，衔接企业需求、算法开发与标准研制。
02 / ML WORKSPACE

海上感知训练平台
让实验可复现、可追溯

将数据、模型、参数与评测结果组织为标准任务，串联批量训练、实验对比与失败重跑。

核心原型完成 · 部分功能联调
＋
核心方法通过任务 ID 关联数据与代码版本、资源需求、执行状态、日志、模型权重和评测结果，支持版本化查询与比较。
迭代闭环关联真实数据、虚幻引擎仿真场景与分场景评测，将 Bad Case 回流到样本补充和重新训练，降低实验复现与问题定位成本。
03 / EDGE–CLOUD SYSTEM

无人船风险预警
从环境感知到避障输入

用局部三维地图表达目标占用与运动状态，结合轨迹预测生成风险热区，规划船端实时处理与云端迭代。

参数化仿真场景 + 量化验收方案
＋
核心方法打通环境表达、风险判断与避障输入，输出结构化风险信息，覆盖小目标漏检、遮挡与通行空间判断等场景。
验证设计在虚幻引擎中组合目标运动、遮挡和环境条件开展批量验证；将距离 ≥4 km、识别率 ≥92%、延迟 ≤600 ms 纳入验收要求，不将这些阈值写成实测结果。
04 / PREDICTIVE CONTROL

海上平台预测控制
机器学习 × 物理模型推演

独立设计风况预测、候选策略推演与评分择优流程，在控制执行前比较姿态风险与泵控投入。

150 组配对仿真 · 累计泵量 −19.85%
＋
核心方法将短时风况预测输入物理模型，批量推演候选压载策略的姿态变化、风险约束与控制代价，配套自动化评测流程。
结果边界19.85% 为论文所用等效模型中的配对仿真结果；中低阈值姿态超限时间有所增加，不代表各项性能全面改善，仍需更高保真模型与试验验证。
